# SkillBridge – Local Skills Marketplace

SkillBridge is a cross-platform Flutter application developed as a Final Year Project (FYP) that connects skilled workers with clients through a secure and user-friendly digital marketplace. The platform enables users to discover local services, post job requests, submit proposals, communicate in real time, and manage contracts from a single application.

Built using **Flutter** and **Firebase**, SkillBridge follows a clean and scalable architecture to deliver high performance, maintainability, and an excellent user experience across Android, iOS, Web, and Desktop platforms.

## Key Features

* 🔐 Secure authentication and user account management
* 👤 Separate roles for **Clients**, **Workers**, and **Administrators**
* 💼 Job posting and job discovery system
* 📄 Proposal submission and management
* 💬 Real-time chat and communication
* 📑 Contract creation and tracking
* ⭐ Ratings and reviews for completed jobs
* 🔔 Push notifications for important updates
* 📊 Admin dashboard for platform management
* ☁️ Firebase integration for authentication, database, and cloud storage

## Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Firebase
* **State Management:** Riverpod
* **Navigation:** GoRouter
* **Database:** Cloud Firestore
* **Authentication:** Firebase Authentication
* **Storage:** Firebase Storage

## Project Objective

The primary objective of SkillBridge is to simplify the process of connecting local clients with skilled professionals by providing a reliable, transparent, and efficient digital platform. The application reduces the time required to find trusted service providers while helping freelancers and skilled workers access more employment opportunities within their communities.

SkillBridge demonstrates modern mobile application development practices, including clean architecture, modular feature-based development, responsive UI design, real-time data synchronization, and cloud-based backend services.
